# Стоп-лист для слагов: мат и оскорбления, русские (в транслите) и английские.
#
# Формат:
#   слово    — запрещено как подстрока: поймает и `superслово42`
#   =слово   — запрещено только целиком (для корней, дающих много ложных
#              срабатываний на нормальных именах)
#   # ...    — комментарий
#
# Слаг перед проверкой складывается: дефисы убираются, похожие на буквы цифры
# заменяются (0->o, 1->i, 3->e, 4->a, 5->s, 7->t, 8->b). Проверяется уже
# транслитерированный слаг, поэтому русские корни пишем латиницей: `хуй`
# попадёт сюда как `huy`.
#
# ВНИМАНИЕ: подстрочное совпадение — грубый инструмент. Фамилия Шитов даст
# `shitov` и попадёт под `shit`. Такие корни лучше заводить через `=`.
# Список наполняется отдельно, здесь только очевидный минимум для старта.
